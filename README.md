# Primeros pasos en Swift 🍎

¡Bienvenido a mi repositorio de aprendizaje de Swift! Este espacio está dedicado a documentar mi progreso, ejercicios y conceptos fundamentales mientras exploro el lenguaje de programación de Apple.

## 🚀 Sobre este repositorio

Este repositorio contiene código fuente, notas y ejemplos prácticos desarrollados durante mi aprendizaje de Swift. El objetivo es asentar las bases del lenguaje, desde la sintaxis básica hasta conceptos más avanzados de programación orientada a objetos y funcional.

## 📋 Contenido del aprendizaje

A medida que avanzo, voy cubriendo los siguientes bloques:

* **Fundamentos:** Variables (`var`), constantes (`let`), tipos de datos (String, Int, Double, Bool).
* **Colecciones:** Arrays (arreglos), Diccionarios y Sets.
* **Flujo de Control:** Sentencias `if`, `else`, `switch` y bucles `for-in`, `while`.
* **Funciones:** Definición, parámetros, etiquetas de argumento y valores de retorno.
* **Optionals:** Gestión de valores nulos, *optional binding* (`if let`), y *force unwrapping*.
* **Estructuras y Clases:** Diferencias entre tipos de valor y tipos de referencia.
* **Protocolos y Extensiones:** Cómo extender la funcionalidad del código existente.

## 🛠 Requisitos

Para ejecutar los archivos de este repositorio, necesitarás:

* **macOS:** La forma más sencilla de programar en Swift.
* **Xcode:** El IDE oficial de Apple (puedes descargarlo desde la App Store).
* **Swift Playgrounds:** Ideal para probar fragmentos de código rápidos.

Alternativamente, si estás en **Windows o Linux**, puedes usar [Swift.org](https://swift.org/download/) para instalar la cadena de herramientas de Swift o utilizar compiladores online como Replit.

## 💻 Cómo ejecutar los ejemplos

1.  Clona este repositorio:
    ```bash
    git clone [https://github.com/Dpaslord/Primeros-pasos-en-Swift.git](https://github.com/Dpaslord/Primeros-pasos-en-Swift.git)
    ```
2.  Abre los archivos `.swift` en Xcode o pégalos en un **Playground**.
3.  ¡Experimenta con el código!
